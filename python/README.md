# Python

Holder's Python libraries. Choose by what you want to do:

- **[`holder/`](holder/) (`holder-python` on PyPI, `import holder`)** The regular Python API for users and developers.
You can script or automate Holder, edit and update your cards and other data and see them real time in the GUI.
If you don't know which to pick, take this one.

- **[`kit/`](kit/), Holder Kit (`holder-kit` on PyPI, `import holderkit`)** is for data scientists,
offline analysis, bulk import or export. You can run it in a notebook or on a server without needing the rest of Holder
being installed or running locally. Use this if you want to use Holder's knowledge management format rather
than interoperating with its applications in real time.

![AI generated image](kit/docs/which_holder_python_api.png)

Each library has its own README with setup and development instructions.
